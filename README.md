# AdvancedPlanting

Мод для Valheim (BepInEx 5), который сажает растения вдоль произвольных кривых: отрезок, дуга, окружность, сплайн через любые точки и заливка замкнутого контура. Любая кривая превращается в изогнутую сетку из параллельных рядов. Есть регулируемая хаотичность разброса и прореживание, чтобы посадки выглядели естественно, а не как линейка.

Отличие от PlantEasily: фигура задаётся контрольными точками, зафиксированными в мире, а не прямоугольником вокруг курсора. Вы ставите точки, ходите вокруг, крутите параметры и видите все будущие растения призраками до того, как потратить хоть одно семя.

## Управление

Работает только в режиме строительства с семенем или саженцем в руках. Все клавиши меняются в `BepInEx/config/kepqa.AdvancedPlanting.cfg`.

| Действие | По умолчанию |
|---|---|
| Поставить контрольную точку под курсором | `Z` |
| Убрать последнюю точку | `Backspace` |
| Сбросить фигуру | `Delete` |
| Сменить тип пути: линия, дуга, окружность, кривая, заливка | `H` |
| Сторона рядов: обе, слева, справа | `J` |
| Выбрать параметр: шаг, ряды, хаотичность, прореживание | `B` |
| Изменить выбранный параметр | `Alt` + колесо |
| Перемешать разброс | `Y` |
| Посадить всю фигуру | ЛКМ, как обычная посадка |
| Включить/выключить мод | `F7` |

Клавиши по умолчанию не пересекаются с игрой. В ванили `F` активирует силу Форсакена, `R` убирает оружие и выкидывает из режима строительства, `X` садит, `G` открывает радиальное меню, `Ctrl` переключает присед, средняя кнопка мыши разбирает постройки.

Пока точек меньше, чем нужно режиму, мод не вмешивается, и посадка работает как в ванили. Нужное число точек: линия 2, дуга и окружность 3, кривая от 2, заливка от 3.

Шаг по умолчанию равен удвоенному радиусу роста растения. Минимальная дистанция между растениями (радиус роста плюс запас) соблюдается всегда, разброс никогда её не нарушает. Поэтому хаотичность становится заметной, только если увеличить шаг. Красные призраки показывают точки, где сажать нельзя, причина видна на панели. Мод отказывается сажать и там, где ваниль разрешила бы, но растение засохнет: чужой биом, жара Ашленда, холод гор.

Каждое растение стоит столько же, сколько в ванили: семена, стамина, прочность культиватора и опыт навыка. Если семена или стамина кончаются посреди фигуры, посадка останавливается, а оставшиеся точки остаются в превью.

## Сборка

Нужны .NET SDK 8 и установленный Valheim с BepInEx 5. Игровые DLL берутся прямо из папки игры, в репозитории их нет.

1. Создайте `src/AdvancedPlanting/Local.props`:
   ```xml
   <Project>
     <PropertyGroup>
       <ValheimPath>D:\Steam\steamapps\common\Valheim</ValheimPath>
       <CopyToGame>true</CopyToGame>
     </PropertyGroup>
   </Project>
   ```
   Вместо файла можно задать переменную окружения `VALHEIM_INSTALL`.
2. `dotnet build src/AdvancedPlanting -c Release`

С `CopyToGame=true` обе DLL (`AdvancedPlanting.dll` и `AdvancedPlanting.Core.dll`) копируются в `BepInEx/plugins/AdvancedPlanting` после каждой сборки. Приватные члены игры открываются через `BepInEx.AssemblyPublicizer.MSBuild` во время сборки.

Пакет `BepInEx.AssemblyPublicizer.MSBuild` скачивается из NuGet сам. Для сборки достаточно `assembly_valheim.dll`, `assembly_utils.dll`, Unity-модулей из `valheim_Data/Managed` и `BepInEx.dll` с `0Harmony.dll` из `BepInEx/core`.

Проверки без игры:

```
dotnet test tests/AdvancedPlanting.Core.Tests        # геометрия
dotnet run --project tools/LayoutPreview -- out      # SVG-превью раскладок
```

## Как устроено

- `src/AdvancedPlanting.Core` — чистая геометрия без зависимостей от Unity: кривые, эквидистанты рядов с обрезкой на вогнутой стороне, детерминированный шум, фильтр минимальной дистанции. Покрыта тестами.
- `src/AdvancedPlanting` — плагин: конфиг, состояние фигуры, проверка точек по правилам игры, пул призраков, отрисовка кривых, HUD, патчи Harmony.
- Патчи: `Player.UpdatePlacementGhost` (обновление превью), `Player.TryPlacePiece` (посадка всей фигуры вместо одной точки), `Player.UpdatePlacement` (колесо с модификатором вместо вращения).

Клик в игре вызывает `TryPlacePiece`, и при успехе ваниль один раз списывает семена, стамину, прочность и даёт опыт. Мод подменяет `TryPlacePiece`: сажает все точки через ванильный `PlacePiece`, за первое растение платит ваниль, за остальные мод по тем же формулам. Сервер и другие игроки видят растения без специальной синхронизации, мод нужен только тому, кто сажает.

Призраки клонируются с ванильного призрака под неактивным родителем, и из клонов вырезаются все скрипты. Поэтому они не создают сетевых объектов и не попадают в списки построек игры.

## Статус

Собирается против `assembly_valheim.dll` текущей версии игры, все сигнатуры сверены с декомпиляцией. В игре ещё не запускался. Самые вероятные места для сюрпризов: шейдер линий (если игра вырезала стандартные шейдеры, линии будут розовыми или невидимыми) и шаг колеса мыши. Первое, что стоит сделать: взять морковку, поставить две точки клавишей `Z`, посадить и посмотреть `BepInEx/LogOutput.log`.

## English

Valheim mod (BepInEx 5) that plants along arbitrary curves: line, arc, circle, free spline and closed-shape fill. Any curve becomes a bent grid of parallel rows. Adjustable jitter and thinning make plantings look natural. Control points are fixed in the world, the preview shows every plant as a ghost before you spend a seed, and every plant goes through the vanilla `PlacePiece`, so resources and multiplayer sync work as usual. Build instructions are above: create `Local.props` with your `ValheimPath`, then `dotnet build src/AdvancedPlanting -c Release`. Default keys: Z add point, Backspace undo, Delete clear, H path type, J row side, B select parameter, Alt+wheel change it, Y reshuffle, left click plants.
